# iljero-assets

일제로(@work_to_zero) 인스타 발행용 **이미지 호스팅** 저장소.

인스타 Graph API 는 이미지를 **공개 URL 로만** 받는다. 로컬 파일은 못 넘긴다.
그래서 여기에 커밋·푸시해서 GitHub Pages 로 서빙하고, 그 주소를 API 에 넘긴다.

```
파일     instagram/<발행일>/01.png
주소     https://jiyu-ng.github.io/iljero-assets/instagram/<발행일>/01.png
```

## 왜 옳은경제(econ-bite)에 얹지 않았나
일제로는 **필명 브랜드**라 저자 실명·회사명·다른 브랜드와 섞으면 안 된다.
이미지 URL 은 게시물에 안 보이지만, 자리부터 갈라두는 게 맞다. (2026-09-08)

## 발행 전 확인
1. push 후 **캐시가 퍼질 때까지 기다린다** — 직후에는 인스타가 이미지를 못 가져온다
2. 각 URL 을 몇 번 curl 해서 200 이 나오는지 본다
3. ⚠️ **내 쪽 200 은 근거가 안 된다** — 인스타는 다른 엣지로 간다.
   2026-09-08 옳은경제 카드가 이걸로 한 번 튕겼다.

## ⚠️ `.nojekyll` 은 지우지 말 것
GitHub Pages 는 기본으로 Jekyll 을 돌리고, **`_` 로 시작하는 폴더를 출력에서 제외**한다.
`_selftest/` 로 테스트했다가 4분간 404 를 보고 "빌드가 느린가" 로 읽을 뻔했다 (2026-09-08).
`.nojekyll` 이 있으면 Jekyll 을 건너뛰어 그 규칙이 사라지고 배포도 빨라진다.
